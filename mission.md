# Mission

Gitboard provides developers with a centralized, local dashboard to monitor and manage their active development workflow across GitHub and GitLab. 

The project aims to reduce context-switching by surfacing critical information—such as CI status, open Merge/Pull Requests, and failed job triage—directly alongside the developer's local git state. By integrating with local forge CLIs (`gh`, `glab`) and local repository roots, Gitboard acts as a lightweight, privacy-respecting command center for local development orchestration.
