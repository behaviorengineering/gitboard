# Review Go CLI (gitboard)

**Spec sources:** `internal/cli/*.go` (Cobra commands, agent guide), `cmd/gitboard/main.go` (version stamp, signals), `Taskfile.yml` (`bin/gitboard`). Contract: `octo-go:cli-command-surface`.

---

## 1. Scope

Default: `internal/cli/` and `cmd/gitboard/`. Narrow if the user names a subcommand only (`init`, `sync`, `serve`).

---

## 2. Entry pattern

- [ ] `main` only stamps the version, sets up the signal context and calls `cli.Execute`.
- [ ] Bare `gitboard` prints the agent guide and exits 0; it never starts serve.
- [ ] Unknown commands exit non-zero with Cobra's "unknown command" message.
- [ ] `RunE` handlers use `cmd.Context()` and `cmd.OutOrStdout()`; domain work lives in `internal/*` and `pkg/*`.
- [ ] No hand-rolled dispatch (`switch args[0]`, `os.Args` routing, `flag.NewFlagSet`).

---

## 3. Subcommands

### init

- [ ] Creates config if missing; never overwrites without explicit design change.
- [ ] Honors `--config` / default XDG path; `--dry-run` writes nothing.

### sync

- [ ] Flags documented in usage / README commands table stay in sync.
- [ ] Interactive vs `--add` / `--remove` / `--dry-run` paths fail clearly; without a terminal the interactive path refuses and names those flags.
- [ ] Writes `projects` via `internal/syncproj` / config helpers.

### serve

- [ ] Loads config; wires forge, localgit, dashboard, server, optional LLM/prune.
- [ ] Default addr is loopback.
- [ ] process-compose path remains `go tool task serve` (scripts); CLI serve stays one-off.

---

## 4. Output and exits

- [ ] Errors to stderr / `log`; success paths quiet or intentional.
- [ ] Help via `-h` / `--help` / `help`, generated by Cobra from `Short` and flag text.
- [ ] The agent guide in `internal/cli/root.go` lists every command and only doc paths that ship.
- [ ] `version` works with no config present.

---

## 5. Report

List CLI wiring issues. If user said **and fix**, apply them and keep usage strings aligned.
