# Overview
This section establishes the operational grounding for Majordomo agents, synthesizing the core mission and architectural principles defined in the project's foundational documents.
## Mission Alignment
Majordomo operates as a coordination layer designed to bridge high-level intent with executable technical workflows. The mission focuses on providing structured, reliable, and context-aware assistance within the Gitboard ecosystem, ensuring that agentic actions are always anchored to the current state of the repository and the user's evolving objectives.
## Architectural Foundation
The architecture follows a Typology-driven approach, where agent capabilities are categorized and constrained by formal package contracts and role definitions. This ensures:
Predictable Interaction: Agents operate within defined capability constraints to maintain system integrity.
Contextual Awareness: By leveraging the refined Typology and journey markers, agents maintain a continuous understanding of the project's progression from discovery to refinement.
Modular Scalability: The system utilizes a structured hierarchy of packages and roles, allowing for the seamless integration of new specialized sub-RLMs.
This grounding serves as the single source of truth for agentic behavior, ensuring all automated reasoning and actions remain consistent with the established project trajectory.
