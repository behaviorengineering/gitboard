# Context branch
This orphan branch holds the project understanding for the served repository. These files remain separate from the default branch; context updates occur via PRs targeting this branch.
## Story vs Typology evidence
Root markdown files (`mission.md`, `architecture.md`, etc.) constitute the teaching story.
`evidence/typology/` contains the Typology seed evidence (such as `architecture_brief.md`) used to propose the current digest. This evidence represents the raw survey results and is distinct from the finalized teaching story or the confirmed `.typology/` catalog.
