Gitboard provides a local, high-visibility dashboard for developers to manage their interaction with remote Git forges (GitHub and GitLab). 

The mission is to reduce cognitive load during context switching by aggregating:
- CI/CD status and failed job triage.
- Open Merge Requests (MRs) and Pull Requests (PRs).
- Local worktree and checkout states.
- Automated branch lifecycle insights (pruning suggestions).

By combining local Git state with remote forge data and optional LLM-powered triage, Gitboard serves as a centralized command center for active development.
