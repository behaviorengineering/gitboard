## Story vs Typology evidence
Root markdown files (`mission.md`, `architecture.md`, etc.) constitute the teaching story, defining the project's purpose and structure.
`evidence/typology/` contains Typology seed evidence (such as `architecture_brief.md`) used to propose the digest. This evidence represents the raw findings of the survey/refine arc and is distinct from the finalized teaching story or the confirmed `.typology/` catalog.
