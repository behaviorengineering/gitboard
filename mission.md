# Mission

Gitboard provides a centralized, local dashboard for developers to monitor their active work across multiple Git providers (GitHub and GitLab). 

The system automates the discovery of repositories and synchronizes remote state (CI status, Merge Requests/Pull Requests) with local filesystem state (clones and worktrees). By integrating agentic LLM workflows, Gitboard assists in triaging failed jobs and managing repository hygiene, turning fragmented forge data into a cohesive, actionable local interface.
