# Mission

  Gitboard provides developers with a centralized, local dashboard to monitor repository health and workflow state across multiple forges (GitHub and GitLab). 

  The project aims to reduce cognitive load by aggregating:
  * CI/CD status and failed job triage.
  * Open Merge Requests and Pull Requests.
  * Local git worktree and checkout states.
  * Automated maintenance suggestions via AI-driven triage and pruning agents.
