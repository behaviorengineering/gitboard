# Chronology
Newest first.
The Majordomo ecosystem evolves through increasing layers of abstraction, moving from local state management to autonomous agentic oversight.
Agentic Pruning: The system incorporates `pruneagent` to investigate local-only or removable branches, shifting the focus from simple observation to active workspace maintenance.
Remote Forge Integration: Connectivity expands via `remotegit`, enabling seamless interaction with GitHub and GitLab APIs to bridge local worktrees with remote repository states.
Observability and Core Domain: The foundation rests on `observability` for error-only inference dumps and `localgit` for inspecting local git state and populating metadata for checkout operations.
