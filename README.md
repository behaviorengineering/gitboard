Gitboard serves as a local code-change dashboard for GitLab and GitHub. It aggregates CI status, open Merge Requests, and failed job triage data alongside local checkout and worktree states. The tool operates by interfacing with the `gh`, `glab`, and `git` CLIs installed on the user's machine, providing a unified view of development activity directly in the local environment.
This orphan branch holds project understanding for the `gitboard` repository.
Never merge these files into the default branch.
Context updates are PRs whose base is this branch.
