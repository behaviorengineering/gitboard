## Story vs Typology evidence
Root markdown files (`mission.md`, `architecture.md`, etc.) constitute the teaching story, providing the high-level narrative and intent of the gitboard project.
The `evidence/typology/` directory contains Typology seed evidence (such as `architecture_brief.md`) captured during the discovery and refinement arc. This evidence supports the proposed structure but does not represent the finalized teaching story or the confirmed `.typology/` catalog.
