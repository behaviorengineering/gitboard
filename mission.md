# Mission

  Gitboard exists to provide developers with a unified, local dashboard for monitoring repository activity across GitHub and GitLab. 

  The primary objectives are:
  - Centralize visibility into CI status and open Merge Requests/Pull Requests.
  - Facilitate failed job triage.
  - Track local checkout and worktree states.
  - Leverage existing local forge CLIs (`gh`, `glab`) and `git` to minimize external dependencies and runtime overhead.
