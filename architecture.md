# Architecture
> Teaching story. Living project architecture for humans and review grounding. Not Typology seed evidence (see `evidence/typology/architecture_brief.md`).
The Majordomo system organizes logic into a collection of specialized packages, each defined by a clear role and a set of capability constraints. Rather than a rigid hierarchy, the architecture emerges from the interaction of these roles, governed by explicit package contracts and objective ledgers.
### Core Structural Principles
Role-Based Organization: Every component exists to fulfill a specific role within the system's lifecycle, moving from initial discovery to refined stability.
Capability-Driven Constraints: Logic is bounded by capability constraints, ensuring that packages interact through well-defined interfaces rather than unrestricted access.
Objective Alignment: The system's shape is guided by slice objectives, where the grouping of modules is driven by the functional goals they collectively achieve.
Evolutionary Mapping: The architecture is not static; it follows a journey from raw snapshots and mechanical groupings toward a refined, clustered state that reflects the actual operational needs of the project.
