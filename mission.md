# Mission
Gitboard serves as a local code-change dashboard for GitLab and GitHub. It orchestrates project discovery and status monitoring by aggregating CI status, open merge requests, and failed job data from remote forges with local git state and worktree information. By integrating with local CLI tools like `gh`, `glab`, and `git`, it provides a unified view for developers to triage tasks and manage their local development environment.
