# Overview
This section establishes the operational grounding for Majordomo agents within the Gitboard ecosystem. The mission centers on providing high-fidelity, local visibility into code-change workflows across GitLab and GitHub, facilitating efficient triage and worktree management.
The architecture utilizes a Typology-driven framework to categorize agentic roles and capabilities. Agents operate within a structured landscape defined by package contracts, capability constraints, and mechanical groupings, ensuring that all automated interventions remain aligned with the established journey and objective ledgers. This grounding ensures that agentic reasoning is anchored in the current state of the repository and the specific mission objectives of the Gitboard environment.
