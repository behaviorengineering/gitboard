# Mission

Gitboard provides a local, high-visibility dashboard for managing the lifecycle of Git repositories across GitHub and GitLab.

The mission is to reduce the cognitive load of developer triage by centralizing:
- **Discovery:** Automatically syncing and tracking GitHub organizations and GitLab groups.
- **Monitoring:** Providing a real-time visual interface for CI status, open Merge Requests/Pull Requests, and failed job triage.
- **Local State:** Bridging the gap between remote forge data and local filesystem state (checkouts and worktrees).
- **Automation:** Assisting in the identification of stale branches and worktrees to maintain a clean local environment.
