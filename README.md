  ## Project Overview

  Gitboard is a local code-change board for GitLab and GitHub. It provides a dashboard for CI status, open MRs/PRs, failed job triage, and local checkout/worktree state using `gh`, `glab`, and `git`.

  ## Context Branch Usage

  This branch is an orphan used to maintain project state. Never merge these files into the default branch. Context updates are submitted as PRs targeting this branch.
